Checks

Three things an export must clear.

  • Missing error workflow

    The export must name an error workflow in its settings, so failed runs reach the error handler.

  • Inline secrets

    Tokens and keys typed straight into node parameters are rejected. They belong in n8n credentials.

  • Unlisted community nodes

    Any node from outside n8n's own packages must be on the repository's allowlist.

How it works

A deny at the last safe moment.

  1. Claude Code is about to run a Bash command. The PreToolUse hook sees it first.
  2. If the command is an n8n import or an API push, the hook runs the validator on the exported workflow JSON.
  3. A clean export passes with no decision, so the normal permission flow applies. Any finding returns a deny with the reason.
  4. Claude reads the reason, opens the matching Agent Skill, applies the fix steps, and tries again.

The same validator belongs in CI, where it covers changes made outside Claude Code.
