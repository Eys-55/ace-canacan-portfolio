How I ship

The model is one step. The controls around it are the job.

Healthcare intake: every request

  1. InquiryWeb form or OCR'd fax
  2. Mask identifiersBefore each Claude API call
  3. Claude tool usePayer, referral, visit reason
  4. Staff approvalFirst-draft replies
  5. GoHighLevelHIPAA-enabled pipelines

Healthcare intake: every release

  1. Prompt changeVersioned
  2. Eval harnessAccuracy, tone, escalation
  3. Deploy-gate hookValidator must clear
  4. ReleaseWith runbook
  • Input
  • Automation
  • Claude
  • Control
  • People
  • System

  1. Mask before the model

    At the healthcare practice, direct identifiers are masked in form and OCR text before each Claude API call. Results are re-linked by record ID.

  2. Version the prompt

    The practice's system prompts are versioned, and each release is scored by a Python eval harness on accuracy, tone, and escalation rules.

  3. Gate the deploy

    In the practice's workflow repositories, a Claude Code hook denies n8n imports until a validator clears the exported workflow JSON.

  4. Keep a person in the loop

    At the legal marketing agency, every AI-drafted follow-up went through a Slack approval queue for intake staff.
