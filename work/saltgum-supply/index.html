Build order

What I shipped, in order.

  1. Jan to Apr 2024

    CX queue audit and ticket triage

    After auditing the CX queue, built self-hosted n8n workflows on Docker, triggered by Gorgias HTTP integrations. They triaged 2,400 monthly tickets for a 6-person team using Shopify GraphQL Admin API return status.

  2. Apr to Jun 2024

    Refund routing

    Shopify return and refund webhooks were sent via REST APIs to Gorgias and a Google Sheets log. Refund resolution went from 4.2 to 1.6 days.

  3. Jun to Aug 2024

    Listing enrichment

    Enriched 1,150 variant listings via Claude tool use against one JSON schema, cutting catalog updates from 3 days to 5 hours per drop.

Safeguards

What keeps it safe to run.

  • Every enriched listing was requested against one JSON schema via Claude tool use.
  • Every refund event was written to a Google Sheets log.
  • Triage read return status from the Shopify GraphQL Admin API.
