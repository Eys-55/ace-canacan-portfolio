System

How the pieces fit.

Build order

What I shipped, in order.

  1. Oct to Dec 2024

    Triage agent

    An n8n and Claude tool-use agent automated case-intake triage for 9 personal-injury firms. Over 8 months it classified 3,200 web leads by case type (motor vehicle, trucking, premises), misclassifying under 3%.

  2. Jan 2025

    Name and incident-date flags

    The agent flagged adverse-party names for each firm's conflict check and incident dates nearing Texas's two-year statute of limitations, as structured JSON. Lead screening dropped from 25 to 8 minutes.

  3. From Jan 2025

    Slack approval queue

    Every AI-drafted follow-up was routed through a Slack approval queue for client-firm intake staff. 84% of 2,100 drafts passed unedited.

  4. Feb to Apr 2025

    The agency's first MCP server

    Shipped as sole engineer: a read-only Python MCP server over the PostgreSQL intake database. Account managers used it from Claude Desktop, and were onboarded with a plain-language guide.

Safeguards

What keeps it safe to run.

  • Every AI-drafted follow-up waited in a Slack approval queue for intake staff.
  • Name flags fed each firm's own conflict check. The decision stayed with the firm.
  • The MCP server was read-only and connected with a read-only database role.
  • Flags were returned as structured JSON, so staff saw the same fields on every lead.
