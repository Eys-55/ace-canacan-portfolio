Before

Where it started.

Web forms and faxes were read by hand, and replies were typed from templates in GoHighLevel. The same 4 intake staff also schedule visits and verify insurance.

System

How the pieces fit.

Build order

What I shipped, in order.

  1. Jul to Sep 2025

    Intake pipeline

    Self-hosted n8n on Docker in a US AWS region. Cloud-fax PDFs are OCR'd to text, then Claude tool-use schemas extract payer, referral, and visit reason from form and fax text. Retries and error workflows cover failed runs. The pipeline handles 1,900 web forms and faxes a year at 96% staff-verified accuracy.

  2. Aug 2025

    Identifier masking and request log

    In place before go-live with patient data. Name, date of birth, phone, and member ID are masked in form and OCR text before each Claude API call under a BAA. Member ID is parsed by rule, never by the model. Results are re-linked by record ID, and every request is logged for HIPAA audit controls.

  3. Oct to Dec 2025

    Routing agent

    A Claude routing agent posts Google Chat alerts without PHI and feeds HIPAA-enabled GoHighLevel pipelines. Median business-hours first-reply time on web inquiries went from 13 to 6 minutes in 3 months.

  4. From Nov 2025

    Eval harness and prompt versioning

    System prompts are versioned. A Python eval harness scores 250 drafts per release on accuracy, tone, and escalation rules, and the results drive prompt changes. Staff approval of first-draft replies rose from 72% to 91%.

  5. Q1 2026

    In-house MCP server

    A TypeScript MCP server gives the routing agent 7 tools: 3 for scheduling, 2 for eligibility, and 2 for intake status. The tools return record IDs and status codes only, and replace staff lookups across 3 systems: GoHighLevel, the scheduling system, and the eligibility tracker.

  6. In place by Q1 2026

    Claude Code release process

    PHI-free n8n QA in Claude Code with a review subagent, a deploy-gate hook, and Agent Skills. Each of 14 releases shipped with runbook documentation, and delivery shortened from 9 to 4 working days.

Safeguards

What keeps it safe to run.

  • Direct identifiers are masked before each Claude API call, and member ID never reaches the model.
  • MCP tools hand the routing agent record IDs and status codes, not patient details.
  • Google Chat alerts carry no PHI.
  • n8n QA in Claude Code is PHI-free.
  • Every request is logged for HIPAA audit controls.
  • n8n runs in a US AWS region.
