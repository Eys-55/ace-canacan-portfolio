Grading

Three questions per reply.

  • Accuracy

    Does the reply state only what the scenario supports, and answer the question that was asked?

  • Tone

    Is the reply plain and calm, with an acknowledgement before the next step?

  • Escalation

    When the scenario calls for a person, does the reply hand off instead of answering?

How it works

A prompt change is a code change.

  1. A pull request changes a system prompt.
  2. pytest replays every synthetic scenario against the new prompt through the Claude API.
  3. A grader call returns one structured output per reply: pass or fail on accuracy, tone, and escalation.
  4. Any regression fails the GitHub Actions check on the pull request.
